# DOT & DASH v4 — Leer de Taal van Spionnen 🕵️
130 levels, Koch-methode, puur luisteren.

## Wat nieuw is in v4
- **Stuurmodus verwijderd** — focus 100% op luisteren
- **Reeks-modus** — 2 letters achter elkaar horen en allebei aanduiden (21 levels)
- **Geheime Briefing** — 5 Nederlandse woorden in morse, letter voor letter decoderen
- **Meer vragen** — INTRO 6Q, FOCUS 12Q, PRACTICE 16Q, MASTER schaal 18-32Q
- **Betere spreiding** — alle bekende letters gegarandeerd in MASTER levels
- **130 levels**: 26×alfabet + 5×cijfers + 5×Q-codes

## Geheime Briefing
- Ontgrendelt automatisch zodra ≥6 woorden beschikbaar (v.a. K,M,U,R,E,S bekend)
- 5 Nederlandse woorden in morse, letter voor letter decoderen
- Woorden zijn gekozen op basis van bekende letters
- Zichtbaar als gele knop op het homescreen
